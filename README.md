# CivilFlow — Atualizações

Canal público de distribuição do CivilFlow para Autodesk Civil 3D 2026.

Baixe o instalador **CivilFlow-Setup.exe** e o manual PDF na seção [Releases](https://github.com/solutionstechnologyinformation-beep/CivilFlow-Atualizacoes/releases).

Salve os desenhos e feche o Civil 3D antes de instalar. Este canal não contém código-fonte, credenciais nem projetos de clientes. Os arquivos-fonte ZIP/TAR gerados automaticamente pelo GitHub contêm apenas esta apresentação, não o código do CivilFlow.

O suporte ao Civil 3D 2027 será tratado em uma versão futura.
